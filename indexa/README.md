# Indexa

Desenvolvimento do projeto Indexa no repositorio [Git](https://github.com/paulo-nazareth/angular) com Angular versão 17.0.3.

## Versões e Configurações

nvm install 18.18.2
nvm use 18.18.2
npm install -g @angular/cli@17.0.3

## Development server

Execute o comando `ng serve` para iniciar um servidor de desenvolvimento. Acesse `http://localhost:4200/`, para ter acesso a página inicial do projeto.

## Comandos

### Criação Projeto

Run `ng new indexa --routing --style=scss`.

### Criação Componente

Run `ng generate component componentes/container`.

Outros Possíveis Comandos `ng generate directive|pipe|service|class|guard|interface|enum|module`.

## Build

Execute `ng build` para compilar o projeto. Os artefatos da compilação serão armazenados no diretório `dist/`.

## Running unit tests

Execute `ng test` para executar os testes unitários via [Karma](https://karma-runner.github.io).

## Running end-to-end tests

Execute `ng e2e` para executar os testes de ponta a ponta por meio da plataforma de sua escolha. (Verificar se será implementado)...
